# Cops vs a Robber
This is a 2D javascript canvas game that I made themed around cops and robbers. The objective is to collect as many coins as possible before the cops catch and arrest you.

## Features:
- Cops and Robbers themed game
- Score system with coins you can collect throughout the game
- 2 random powerups (Stun and invincibility )
- Wanted level mechanic that spawns cops that are faster (Inspired by GTA)
